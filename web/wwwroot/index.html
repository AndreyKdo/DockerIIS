DockerWebinar IIS (Windows) → APIs (Windows) → SQL Server (Linux/VM)

Laboratorio hibrido · microservicios independientes

Clientes y pagos, servidos por dos motores Docker distintos

Este sitio corre en un contenedor Windows (IIS) y habla, por red TCP/IP, con cuatro microservicios .NET, uno por cada operación, también en contenedores Windows.

Esos microservicios insertan y consultan datos en un SQL Server 2022 corriendo como contenedor Linux, dentro de una máquina virtual Ubuntu 26.04 LTS. Si apagas cualquiera de los cuatro microservicios, los otros tres siguen funcionando: eso es lo que queremos evidenciar aquí.
